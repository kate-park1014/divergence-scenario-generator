## 3화 — 과열된 서버의 비명

**prologue**
> 낡은 전산실에 위기가 찾아왔다.
> 서버 과열로 보안 시스템마저 마비되고,
> 모든 것이 녹아내리는 듯한 뜨거운 공기 속에서
> 누군가는 또다시 절박한 도움을 기다리고 있었다.
> 이번에는 어떤 선택이 그들을 구원할까.

**방 1**
- **나레이션**: 낡은 전산실의 냉각수 파이프실, 서버 과열로 보안 시스템이 마비된다.
- _(enter: 카이)_
- **카이**: 이대론 안 돼. 시스템이 전부 먹통이야.
- **파티(아무나)**: 지난번 전원 코드를 뽑았다가 서버가 과열됐지.
- **character_1**: 으으, 여기 너무 뜨거워.
- **파티(아무나)**: 이번엔 과열된 서버를 식힐 방법이 필요해.
- _(shake: 나레이션)_
- **나레이션**: 경고등이 깜빡이며 메시지를 띄운다: "과열된 서버에 냉각수를 부으면 해결된다."
- **파티(아무나)**: 냉각수를 붓는다고? 직접적인 해결책 같군.
- **카이**: 저 방법이라면... 내가 데이터를 복구할 시간을 벌 수 있을지도 몰라.

**방 3**
- **파티(아무나)**: 카이를 돕기 위해 이 방법을 시도해야겠어.
- **파티(아무나)**: 전원 코드를 뽑는 것과는 다른 방식이야. 서버를 식히는 일이니까.
- **character_2**: 왠지 불안해.
- _(enter: 일반 보스)_
- **일반 보스(냉각 담당자)**: 감히 냉각수에 손을 대려는 건가!
- **일반 보스(냉각 담당자)**: 냉각수에 이물질을 넣으면 시스템 전체가 망가진다고!
- **파티(아무나)**: 그는 자기 구역을 지키려 할 뿐이다.
- **파티(아무나)**: 하지만 지금은 카이를 돕는 게 우선이야.
- **나레이션**: 과열된 서버에 냉각수를 붓자, 서버 온도가 내려가는 듯 보인다.

**방 5**
- _(enter: 카이)_
- **카이**: 덕분에 한숨 돌렸어. 이제 다시 복구 작업을 시작할 수 있겠어.
- **파티(아무나)**: 다행이다. 상황이 나아지는 것 같아.
- **character_3**: 몸이 으스스해.
- **나레이션**: 낡은 전산실의 모든 데이터 저장 장치에서 데이터 스크린 조각이 흐릿해진다.
- **파티(아무나)**: 스크린 조각이 왜 흐려지는 거지? 무슨 일이 생긴 것 같군.
- **카이**: 데이터 유출... 설마.

**방 9**
- _(enter: 카이)_
- **카이**: 큰일이야! 데이터 유출이 멈추질 않아!
- **파티(아무나)**: 우리가 한 행동 때문에 벌어진 일인가.
- **파티(아무나)**: 모든 스크린 조각들이 점점 더 흐릿해지고 있어.
- **character_4**: 망했어...
- **카이**: 이건... 단순한 과열 문제가 아니었어.

**방 15**
- **일반 보스(냉각 담당자)**: 내 경고를 무시하고 결국 이 사달을 냈군!
- **일반 보스(냉각 담당자)**: 데이터 유출이라니! 모든 게 너희가 멋대로 냉각수에 손댄 탓이다!
- **파티(아무나)**: 우린 카이를 돕기 위해 한 일이다.
- **파티(아무나)**: 하지만 우리는 카이를 돕는 것이 급선무라고 생각했어.
- **일반 보스(냉각 담당자)**: 이 구역의 시스템은 내가 지킨다! 더 이상 방해하지 마라!

# 4화 설계표 — 유출된 정보의 소동

- 장소: 데이터 폐기물 처리장 / 주 NPC: 닥스 / 주인공 행동: **데이터 유출 출처 장치를 분해한다** / 흔적: 왜곡된 단말 이미지 / 일반 보스: 데이터 파쇄원 (ally)

## 스토리 방
- **방 1**: 닥스가 데이터 유출로 자신의 신상 정보가 공개된 것에 격분한다. 왜곡된 단말 이미지가 나타나 유출된 데이터의 출처 장치를 분해하여 흔적을 지우라는 해결책을 보여주지만, 아직 실행하지 않는다.
- **방 3**: 주인공은 닥스를 돕기 위해 데이터 유출 출처 장치를 분해한다. 당장 데이터 유출이 멈추고 주변의 어지러운 정보 스트림이 사라진다.
- **방 5**: 분해된 장치 옆의 데이터 스크린 조각에 작게 금이 간다. 처리장 바닥의 폐기물 분류 라벨 정보가 서로 뒤바뀌기 시작한다.
- **방 7**: 데이터 스크린 조각이 더 크게 갈라지며 보안 경고등이 꺼진다. 주변 사람들의 업무 기록과 개인 정보가 무작위로 섞여 화면에 출력된다.
- **방 10**: 데이터 파쇄원이 나타나 이곳의 폐기물은 특별 관리 대상이라며 앞을 가로막고 전투가 벌어진다. 주인공이 승리하지만 데이터 스크린 조각이 완전히 깨지고 핵심 보안 시스템이 무력화된다.

## 카드 칸
- **칸 A**
  - 열린 것: 왜곡된 단말 이미지가 가리키는 출처 장치의 위치.
  - 정하는 것: 처리장 사람들이 유출된 타인의 정보를 캐내려는 시도를 도울지 말지.
  - 깨면 안 되는 사실: 출처 장치는 아직 분해되지 않았다.
- **칸 B**
  - 열린 것: 분해된 출처 장치에서 나온 깨끗한 데이터 부품들.
  - 정하는 것: 유출이 멈춰 안정된 데이터를 이용해 사람들의 개인적인 부탁을 들어줄지 말지.
  - 깨면 안 되는 사실: 장치는 분해되었고 유출은 멈췄으며 부작용은 아직 없다.
- **칸 C**
  - 열린 것: 라벨 정보가 뒤섞여 잘못 쌓인 폐기물 더미.
  - 정하는 것: 정보가 꼬여 잘못된 작업을 하는 사람들의 혼란을 바로잡을지 방치할지.
  - 깨면 안 되는 사실: 스크린 조각에 금이 가고 정보 섞임 현상이 시작되었다.
- **칸 D**
  - 열린 것: 엉망진창으로 뒤섞여 출력되는 처리장 업무 시스템.
  - 정하는 것: 기록이 섞여 억울한 일을 당하거나 싸우는 사람들을 중재할지 무시할지.
  - 깨면 안 되는 사실: 스크린 조각이 깨지기 직전이며 보안 시스템이 무력화되고 있다.

## 장소의 작은 인물·물건
- `toma` 토마 (person): 쓸만한 폐기물 데이터를 몰래 빼돌려 파는 잡동사니 상인
- `bex` 벡스 (person): 처리장의 말단 폐기물 분류 작업자. 승진을 간절히 원한다.
- `sorter` 구형 분류기 (object): 데이터를 파쇄하는 오래된 기계로 내부에 유출된 정보가 끼어 있다.

## 기억 계획
- **A → C** (toma): 유출된 정보 속에서 다른 상인의 비밀 거래 기록을 찾아달라고 한다.
  - easy: 기록을 찾아주고 당장 값비싼 부품을 받는다. / hard: 남의 정보를 캐는 것을 거절하고 욕을 먹는다.
  - 돌아옴: 정보가 섞일 때, 쉽게 도와줬다면 토마의 장부가 고철 폐기물 목록과 섞여 큰 손해를 보고, 거절했다면 장부를 아날로그로 따로 관리해 피해를 피한다.
- **B → D** (bex): 유출이 멈춘 틈을 타 자신의 인사 고과 데이터를 조작해달라고 부탁한다.
  - easy: 데이터를 조작해주고 약간의 크레딧을 얻는다. / hard: 조작을 거절하고 벡스의 원망을 듣는다.
  - 돌아옴: 정보가 완전히 뒤죽박죽될 때, 쉽게 도와줬다면 벡스의 고과 기록이 청소 로봇의 폐기 기록과 섞여 해고당할 위기에 처하고, 거절했다면 원본 기록이 남아 혼란 속에서도 홀로 정상을 유지한다.

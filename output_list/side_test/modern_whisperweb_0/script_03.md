## 3화 — 과열된 서버의 비명

**prologue**
> 낡은 전산실에 과열 경고음이 울려 퍼진다.
> 보안 시스템이 마비된 가운데, 냉각수 파이프실에서는 카이가 절박하게 작업 중이다.
> 서버 온도는 계속해서 치솟고, 데이터 복구는 난항을 겪는다.
> 이 혼돈 속에서, 익숙한 경고등이 깜빡이며 조언을 건넨다.

**방 1**
- **나레이션**: 낡은 전산실의 냉각수 파이프실, 뜨거운 공기가 가득하다.
- _(enter: 카이)_
- **카이**: 서버 과열 때문에 모든 게 엉망이야. 보안 시스템도 마비돼서 복구가 힘들어.
- **파티(아무나)**: 지난번 시스템 전원을 뽑았다가 서버가 과열됐지. 이번엔 냉각 문제니 다른 방식이 필요하다.
- **나레이션**: 경고등이 깜빡이며 메시지를 띄운다: '과열된 서버에 냉각수를 부으면 해결된다.'
- **파티(아무나)**: 전원 문제는 직접 건드려서 문제가 생겼지만, 냉각수를 붓는 건 시스템의 흐름을 돕는 일이다. 카이를 위해 시도해 보자.
- _(enter: 일반 보스)_
- **일반 보스(냉각 담당자)**: 안 돼! 냉각수에 이물질을 넣으면 파이프가 막히고 시스템이 망가진다!
- **파티(아무나)**: 과열된 서버를 살리는 게 먼저다. 이분은 그저 자기 관리 구역을 지키려는 것뿐이겠지.
- **나레이션**: 과열된 서버에 냉각수를 붓자, 서버 온도가 눈에 띄게 내려가는 것처럼 보인다.
- **character_1**: 휴, 다행이다.
- **나레이션**: 그러나 이내 낡은 전산실의 모든 데이터 저장 장치에서 데이터 스크린 조각이 흐릿해지기 시작한다. 데이터 유출이 시작된 것이다.

**방 3**
- **나레이션**: 전산실 곳곳의 데이터 저장 장치에서 정보들이 흘러나간다.
- _(enter: 카이)_
- **카이**: 이런, 데이터 유출이 시작됐어! 서버 과열은 잡았지만 더 큰 문제가 생겼어.
- **파티(아무나)**: 냉각수를 부은 것이 이런 결과를 낳다니… 예상치 못한 일이다.
- **파티(아무나)**: 데이터 유출이 이렇게 심각할 줄이야. 어서 막아야 해.
- **character_2**: 어떡하면 좋지.

**방 5**
- **나레이션**: 데이터 유출은 걷잡을 수 없이 퍼지고 있었다.
- _(enter: 카이)_
- **카이**: 데이터 스크린 조각들이 흐릿해지고 있어. 이러다간 모든 정보가 사라질 거야!
- **파티(아무나)**: 이대로 두면 도시의 모든 정보가 유출될 것이다. 더 이상 지켜볼 수만은 없다.
- **character_3**: 뭔가 해야 해!

**방 9**
- **나레이션**: 데이터 유출은 점점 더 가속화되고, 전산실은 절박한 침묵에 휩싸였다.
- _(enter: 카이)_
- **카이**: 손쓸 방법이 없어 보여… 이대로 모든 것을 잃게 되는 걸까?
- **파티(아무나)**: 우리가 무엇을 놓치고 있는 걸까? 계속해서 상황이 나빠지고 있다.
- **파티(아무나)**: 이 모든 혼란을 멈출 방법을 찾아야만 한다.

**방 15**
- **나레이션**: 데이터 유출의 근원지에 도착하자, 냉각 담당자가 다시 앞을 막아섰다.
- _(enter: 일반 보스)_
- **일반 보스(냉각 담당자)**: 내 구역을 더 이상 망치게 둘 수 없다! 지난번 경고를 무시하고 냉각수를 부은 결과가 이것이다!
- **파티(아무나)**: 당신은 이 구역을 지키려는 거겠지만, 지금은 데이터 유출을 막는 게 더 중요해.
- **일반 보스(냉각 담당자)**: 나는 내 할 일을 할 뿐이다. 더 이상 시스템에 손대지 마라!

**방 15 · win_dialogue**
- **나레이션**: 냉각 담당자를 제압했지만, 데이터 유출은 멈추지 않고 계속되고 있다.
- _(enter: 카이)_
- **카이**: 겨우 막았지만… 데이터 스크린 조각이 점점 더 흐릿해지고 있어. 모든 정보가 곧 사라질 거야!
- **파티(아무나)**: 이대로는 안 된다. 다음에는 더 근본적인 방법을 찾아야 한다.

**방 15 · lose_dialogue**
- **나레이션**: 냉각 담당자의 완강한 저항에 막혀, 더 이상 나아갈 수 없었다.
- **일반 보스(냉각 담당자)**: 봤지? 내 말을 들었어야 했다. 이제 아무것도 할 수 없어.

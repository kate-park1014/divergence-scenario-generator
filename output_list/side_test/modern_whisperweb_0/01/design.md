# 1화 설계표 — 엉뚱한 데이터 복구

- 장소: 낡은 서버 랙 / 주 NPC: 에코 / 주인공 행동: **데이터 스크린 조각을 깨뜨린다** / 흔적: 낡은 스피커 음성 / 일반 보스: 전산실 보안관 (warn)

## 스토리 방
- **방 1**: 정보 브로커 에코가 엉망이 된 데이터를 복구하려다 난감해한다. 낡은 스피커에서 흘러나오는 위스퍼 웹의 음성이 데이터 스크린 조각을 깨뜨리면 새로운 질서가 생긴다며 해결책을 제시한다.
- **방 3**: 전산실 보안관이 데이터를 함부로 깨뜨리면 모든 것이 꼬인다며 막아서지만, 주인공은 에코를 위해 데이터 스크린 조각을 깨뜨린다. 당장 에코의 데이터가 정상적으로 복구된 것처럼 보인다.
- **방 5**: 낡은 서버 랙 주변의 작은 전광판들이 엉뚱한 문자를 출력하기 시작한다. 데이터 스크린 조각을 깬 여파가 처음으로 작게 나타난다.
- **방 7**: 서버 랙에 연결된 주변 장치들의 정보가 뒤죽박죽 섞여 오작동하는 것을 확인한다. 데이터 스크린 조각이 깨지면서 정보의 연결 고리가 끊어져 일상이 꼬여버린 것이다.
- **방 10**: 사태를 더 악화시키지 못하게 막아서는 전산실 보안관과 전투를 벌인다. 보안관을 제압하지만, 디지털 표지판들의 우스꽝스러운 오작동은 멈추지 않고 전산실 밖으로 퍼질 조짐을 보인다.

## 카드 칸
- **칸 A**
  - 열린 것: 새로운 질서를 약속하는 낡은 스피커의 음성.
  - 정하는 것: 데이터 스크린 조각을 깨면 생길 이득을 좇아 규칙을 무시할지 결정한다.
  - 깨면 안 되는 사실: 주인공은 아직 데이터 스크린 조각을 깨뜨리지 않았다.
- **칸 B**
  - 열린 것: 당장 정상적으로 작동하는 것처럼 보이는 낡은 서버 랙.
  - 정하는 것: 조각을 깬 후 나타난 일시적인 데이터 복구 현상을 이용해 이득을 취할지 결정한다.
  - 깨면 안 되는 사실: 데이터 스크린 조각을 깬 부작용이 아직 눈에 띄게 나타나지 않았다.
- **칸 C**
  - 열린 것: 오류 문자를 뿜어내며 깜빡이는 작은 전광판.
  - 정하는 것: 엉뚱하게 변해버린 주변 정보를 억지로 수습할지 그대로 둘지 결정한다.
  - 깨면 안 되는 사실: 주인공과 에코는 아직 전산실 보안관을 다시 만나지 않았다.
- **칸 D**
  - 열린 것: 정보가 섞여 통제 불능 상태가 된 서버 주변 장치들.
  - 정하는 것: 뒤죽박죽 꼬여버린 사람들의 데이터를 방치할지 도울지 결정한다.
  - 깨면 안 되는 사실: 전산실 보안관이 데이터 훼손의 원인을 찾아 주인공을 추적 중이다.

## 장소의 작은 인물·물건
- `ryan` 라이언 (person): 낡은 서버 랙 정비공. 꼬여버린 부품 주문 데이터를 즉시 수정하고 싶어한다.
- `mia` 미아 (person): 데이터 밀수꾼. 자신의 암호화된 파일 압축을 단번에 풀고 싶어한다.
- `old_cable` 낡은 케이블 뭉치 (object): 엉킨 케이블 뭉치로, 데이터를 불안정하게 전송한다.

## 기억 계획
- **A → C** (ryan): 라이언이 부품 주문 데이터를 빨리 고치기 위해 데이터 스크린 조각의 힘을 조금만 빌려달라고 한다.
  - easy: 조각의 힘을 흉내 내어 데이터를 강제로 덮어씌우고 당장 주문을 통과시킨다. / hard: 위험하다며 거절하고 정석대로 복잡한 수동 코딩을 돕느라 시간이 오래 걸린다.
  - 돌아옴: 조각의 힘을 썼다면 부품 대신 엉뚱한 장난감들이 잔뜩 배달되어 라이언이 우스꽝스러운 상황에 처한다. 거절했다면 주문이 늦었지만 정확한 부품이 도착해 라이언이 안도한다.
- **B → D** (mia): 미아가 암호화된 파일을 빨리 풀기 위해 깨진 데이터 스크린 조각의 파편을 이용하게 해달라고 한다.
  - easy: 파편을 이용해 암호를 강제로 해제하여 미아가 즉시 데이터를 얻게 해준다. / hard: 파편 사용을 막고 미아가 스스로 천천히 암호를 풀도록 둔다.
  - 돌아옴: 파편을 쓰게 해줬다면 미아의 데이터가 누군가의 개인 일기장과 섞여버려 완전히 쓸모가 없어진다. 거절했다면 미아가 고생 끝에 안전하게 자신의 데이터만 해독해낸다.

# 3화 설계표 — 과열된 서버의 비명

- 장소: 냉각수 파이프실 / 주 NPC: 카이 / 주인공 행동: **과열된 서버에 냉각수를 붓는다** / 흔적: 경고등 깜빡임 / 일반 보스: 냉각 담당자 (warn)

## 스토리 방
- **방 1**: 과열된 서버 열기 때문에 냉각수 파이프실의 보안 시스템이 멈춰 카이가 복구 작업을 진행하지 못하고 있다. 벽면의 경고등 깜빡임이 특정 파이프를 가리키며 과열된 서버에 냉각수를 부으면 즉시 식는다는 암시를 준다. 주인공은 이를 확인하고 해결책을 고민한다.
- **방 3**: 주인공은 카이를 돕기 위해 과열된 서버 구역에 냉각수를 붓는다. 냉각 담당자가 나타나 냉각수에 이물질이 들어가면 시스템이 망가진다고 경고하지만, 주인공은 무시하고 냉각수를 붓는다. 서버 온도가 즉시 내려가며 카이가 작업을 재개한다.
- **방 5**: 서버 온도는 내려갔지만, 파이프 주변의 데이터 저장 장치들에서 데이터 스크린 조각의 내용이 흐릿해지기 시작한다. 주인공은 냉각수에 섞여 들어간 무언가 때문에 데이터가 번지는 현상을 처음 목격한다.
- **방 7**: 흐릿해진 데이터 스크린 조각들이 압력을 이기지 못하고 깨져버린다. 깨진 조각을 통해 정보가 뒤죽박죽 섞여 파이프실 내의 각종 기기 오작동과 엉뚱한 정보 출력이 일어나는 것을 확인한다.
- **방 10**: 냉각 담당자가 나타나 주인공의 행동으로 데이터 유출이 걷잡을 수 없게 되었다며 주인공을 물리력으로 막아선다. 전투에서 승리하지만, 데이터 스크린 조각들이 망가진 채로 남아있고 다음 구역의 서버까지 과열 경고등이 켜지기 시작한다.

## 카드 칸
- **칸 A**
  - 열린 것: 냉각수 밸브와 과열된 파이프 주변 구역
  - 정하는 것: 당장의 과열 문제를 빠르고 편한 방법으로 덮을지, 정석대로 둘지 정한다.
  - 깨면 안 되는 사실: 카이는 여전히 작업을 못 하고 대기 중이며 주인공은 아직 냉각수를 서버에 붓지 않았다.
- **칸 B**
  - 열린 것: 온도가 내려가 쾌적해진 파이프실 일부 구역
  - 정하는 것: 차가워진 환경을 이용해 즉각적인 이득을 취할지 정한다.
  - 깨면 안 되는 사실: 주인공이 서버에 냉각수를 부었고, 냉각 담당자는 물러났으며 데이터 유출 조짐은 아직 모른다.
- **칸 C**
  - 열린 것: 데이터가 흐릿해지고 표면이 번지기 시작한 장치들
  - 정하는 것: 오염된 기기나 인물에게 개입하여 문제를 수습할지 방치할지 정한다.
  - 깨면 안 되는 사실: 데이터 스크린 조각들이 깨져 정보가 섞이는 대규모 오작동은 아직 발생하지 않았다.
- **칸 D**
  - 열린 것: 깨진 데이터 스크린 조각으로 인해 정보가 뒤죽박죽이 된 현장
  - 정하는 것: 혼란에 빠진 사람들을 돕다가 손해를 볼지, 무시하고 지나갈지 정한다.
  - 깨면 안 되는 사실: 냉각 담당자는 아직 돌아오지 않았고, 주인공은 파이프실 끝으로 이동 중이다.

## 장소의 작은 인물·물건
- `piping_tech` 배관 수리공 (person): 냉각수 파이프의 미세한 균열을 땜납으로 막으려 하지만 재료가 부족하다.
- `server_cleaner` 서버 청소부 (person): 파이프실 구석에서 과열로 인해 녹아내린 케이블을 치우며 불평하고 있다.
- `coolant_valve` 비상 냉각수 밸브 (object): 아직 봉인되어 있으나 강제로 열면 소량의 냉각수를 바로 뺄 수 있다.

## 기억 계획
- **A → C** (piping_tech): 배관 수리공이 파이프 균열을 막기 위해 주변의 예비 부품을 달라고 한다.
  - easy: 부품을 주어 당장 수리가 완료되고 작은 보상을 받는다. / hard: 부품을 아끼기 위해 거절하여 그가 힘겹게 임시방편으로 구멍을 막는다.
  - 돌아옴: 부품을 주었다면 주인공이 부은 냉각수로 인해 수리한 부분이 압력을 못 이기고 터져 데이터 스크린 조각들이 쏟아져 나와 엉망이 된다. 거절했다면 임시방편으로 막은 곳이 오히려 틈을 벌려 압력을 흘려보내 안전하다.
- **B → D** (server_cleaner): 청소부가 작업 속도를 높이기 위해 방금 차가워진 파이프 표면의 이슬을 닦아낼 도구를 빌려달라고 한다.
  - easy: 도구를 빌려주어 청소가 빨리 끝나고 소소한 이득을 얻는다. / hard: 빌려주지 않아 그가 불평하며 느리게 손으로 청소한다.
  - 돌아옴: 도구를 빌려주었다면 이슬에 섞인 유출 데이터가 스크린 조각에 닿아 청소부의 개인 정보가 뒤죽박죽 섞이며 혼란에 빠진다. 빌려주지 않았다면 데이터 유출을 피해서 안전하다.

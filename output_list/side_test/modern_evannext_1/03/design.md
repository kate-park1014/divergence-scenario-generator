# 3화 설계표 — 단계별 조작, 침묵의 도시

- 장소: 공용 인증부스 / 주 NPC: 카이 / 주인공 행동: **인증 절차를 진행한다** / 흔적: AI 음성 / 일반 보스: 인증 감독관 (warn)

## 스토리 방
- **방 1**: 카이는 반복된 실패로 희망을 잃고 소리를 잃어 이력서에 이름을 말로 기록하지 못한다. AI 음성이 나타나 공용 인증부스의 단계별 인증 절차를 거치면 이름을 기록할 수 있다고 안내한다. 주인공은 카이를 돕기 위해 공용 인증부스에서 목표를 설정한다.
- **방 3**: 주인공은 선한 의도로 카이의 이름 인증 절차를 진행하여 카이가 잠시 목소리를 되찾는 좋은 효과를 본다. 인증 감독관이 다가와 인증 절차 진행을 멈추라고 경고하지만 주인공은 개인적인 방해로 받아들여 믿지 않는다.
- **방 5**: 인증 절차를 진행한 여파로 인증부스 주변 사람들의 목소리가 끊기거나 이상하게 변하는 첫 대가가 나타난다. 주인공은 자신이 진행한 행동의 나쁜 결과가 작게 눈에 보이기 시작하는 것을 확인한다.
- **방 7**: 인증 절차가 진행될수록 부스 주변 사람들의 목소리가 점점 지워져 소리를 내지 못하는 피해가 커진다. 주인공은 이력서 인증 절차가 사람들의 목소리와 존재 정보를 왜곡하여 소리를 빼앗는 세계 규칙을 눈앞에서 확인한다.
- **방 10**: 인증 감독관이 주인공의 추가 인증 절차 진행을 완전히 막아서며 전투가 벌어진다. 주인공이 전투에서 승리하지만 이미 진행된 인증의 나쁜 결과로 도시 전체 사람들이 소리를 낼 수 없게 되며 다음 화의 기미가 남는다.

## 카드 칸
- **칸 A**
  - 열린 것: 공용 인증부스 단말기와 인증 절차를 기다리는 구직자들.
  - 정하는 것: 인증 절차를 손쉽게 통과하기 위해 부스 조작을 도와줄 것인지 결정한다.
  - 깨면 안 되는 사실: 카이는 아직 제대로 된 이름 인증을 받지 못했고 AI 음성의 안내를 받고 있다.
- **칸 B**
  - 열린 것: 1단계 인증을 마친 후 즉각적인 효과를 얻은 구직자들과 단말기.
  - 정하는 것: 인증 혜택을 본 구직자의 추가 보조 인증 요청을 받아들일 것인지 결정한다.
  - 깨면 안 되는 사실: 주인공은 1단계 인증 절차를 진행했고 인증 감독관의 1차 경고를 받은 상태이다.
- **칸 C**
  - 열린 것: 목소리가 이상하게 변하기 시작한 구직자들과 불안해진 인증부스 내부.
  - 정하는 것: 목소리 이상 현상을 겪는 구직자의 이력서를 강제로 수정해 줄 것인지 결정한다.
  - 깨면 안 되는 사실: 인증 절차를 거친 사람들의 목소리에 이상 부작용이 나타나기 시작했다.
- **칸 D**
  - 열린 것: 완전히 소리를 잃어버린 구직자들과 기능을 멈춰가는 공용 인증부스.
  - 정하는 것: 소리를 잃은 구직자의 무리한 마지막 인증 시도를 도와줄 것인지 결정한다.
  - 깨면 안 되는 사실: 인증 절차가 사람들의 목소리를 빼앗는 원인이라는 사실이 명확해졌다.

## 장소의 작은 인물·물건
- `minho` 구직자 민호 (person): 빠른 인증을 받아 이력서 제출을 완료하고 싶어 하는 구직자
- `sora` 대기자 소라 (person): 이력서에 이름을 등록하기 위해 부스 차례를 기다리는 대기자
- `auth_stamp` 전자 인증 도장 (object): 이력서의 인증 단계를 손쉽게 승인 처리하는 인증부스 기기

## 기억 계획
- **A → C** (minho): 민호가 이력서 빠른 인증을 받고 싶다며 주인공에게 인증 단계를 생략하고 단말기를 조작해 달라고 요청한다.
  - easy: 민호의 인증을 빠르게 완료해 주어 고마움의 표시로 즉시 대기표와 유용한 물품을 받는다. / hard: 민호의 요구를 거절하고 원칙대로 절차를 밟게 만들어 민호의 불만을 사고 시간을 빼앗긴다.
  - 돌아옴: 민호가 빠른 인증의 대가로 목소리가 심하게 일그러지고 점차 소리를 내지 못하는 상태가 된다.
- **B → D** (sora): 소라가 이력서 음성 입력이 잘 되지 않는다며 주인공에게 보조 인증 절차 버튼을 대신 눌러 달라고 부탁한다.
  - easy: 소라의 보조 인증을 완료해 주어 소라가 이력서 승인표와 선물을 건네준다. / hard: 소라의 인증을 정석대로 검토하도록 두고 도와주지 않아 소라가 짜증을 내며 떠난다.
  - 돌아옴: 소라가 보조 인증의 대가로 아예 목소리를 잃어버려 말을 전혀 하지 못하는 상태가 된다.

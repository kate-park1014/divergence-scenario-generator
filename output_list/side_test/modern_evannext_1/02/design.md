# 2화 설계표 — 정리를 가장한 혼란

- 장소: 정보 검색실 / 주 NPC: 니아 / 주인공 행동: **이름 정보를 정리한다** / 흔적: 온라인 게시글 / 일반 보스: 데이터 관리자 (ally)

## 스토리 방
- **방 1**: 정보 검색실에서 니아는 린의 이름이 뒤섞인 상태를 보며 이름이 사라지면 이력서에 기록을 남길 수 없다고 불안해한다. 주인공은 단말기에서 이력서 관련 이름 정보를 정리해 복구할 수 있다는 온라인 게시글을 발견하고 이를 시도하기로 결심한다.
- **방 3**: 주인공은 온라인 게시글의 지시대로 단말기에서 린의 이름 정보를 정리한다. 화면상의 린의 이력서 데이터가 깔끔하게 정리되고 린이 잠시 안정을 되찾는 즉각적인 효과가 나타난다.
- **방 5**: 단말기 화면에 표시된 린의 이름에 전혀 다른 글자가 섞여 나타나기 시작한다. 검색실 안의 다른 대기자 명단에서도 이름 표기가 미세하게 변형되는 첫 조짐이 발생한다.
- **방 7**: 린의 이름이 완전히 엉뚱한 이름으로 바뀌어 버리고, 검색실 안의 지원자들은 이름 대신 무작위 숫자로 불리기 시작한다. 주인공은 이름 정보를 정리하는 과정에서 이력서에 거짓과 과장이 덧씌워져 본래 존재가 지워졌음을 알게 된다.
- **방 10**: 데이터 관리자가 나타나 이름 정리는 필수적인 절차라며 주인공이 조사를 계속하거나 밖으로 나가는 것을 가로막는다. 주인공은 전투 끝에 데이터 관리자를 물리치지만, 사람들의 이름이 숫자로 변한 결과는 되돌리지 못한 채 다음 구역으로 향하는 문이 열린다.

## 카드 칸
- **칸 A**
  - 열린 것: 온라인 게시글에 적힌 이력서 이름 정보 정리 안내문
  - 정하는 것: 이력서 정보를 거짓으로 꾸며 단말기에 넣으려는 사람의 요구를 들어줄지 결정한다.
  - 깨면 안 되는 사실: 주인공은 아직 린의 이력서 데이터를 직접 정리하지 않았다.
- **칸 B**
  - 열린 것: 린의 이력서 데이터가 단말기 화면에 안정적으로 표시되는 상태
  - 정하는 것: 이름 정보 정리의 효과를 긍정하며 주변 사람들의 이력서 데이터 처리 요구를 도울지 결정한다.
  - 깨면 안 되는 사실: 이름 정리의 부작용이 아직 겉으로 드러나지 않아 시스템이 정상적으로 보인다.
- **칸 C**
  - 열린 것: 린의 이름 표기에 낯선 글자가 섞여 출력되는 단말기 화면
  - 정하는 것: 단말기 오류로 이름 표기가 뒤틀리기 시작한 사람을 도울지 자신의 경로를 우선할지 결정한다.
  - 깨면 안 되는 사실: 주인공은 이름 뒤섞임이 과장된 정보 정리 때문이라는 진실을 완전히 파악하지 못했다.
- **칸 D**
  - 열린 것: 검색실 안 사람들의 이름이 숫자로 호명되기 시작한 혼란
  - 정하는 것: 이름을 잃고 숫자로 불리며 혼란에 빠진 사람들을 수습할지 방치할지 결정한다.
  - 깨면 안 되는 사실: 데이터 관리자가 정보 검색실로 접근하고 있어 정리가 시급한 상황이다.

## 장소의 작은 인물·물건
- `seeker` 초조한 구직자 (person): 자신의 이력서 경력을 과장하여 단말기에 등록하려는 지원자
- `clerk` 단말기 담당자 (person): 정보 검색실의 단말기 이용과 출력 업무를 관리하는 직원
- `terminal` 공용 검색 단말기 (object): 이력서와 인적 사항 데이터를 열람하고 수정할 수 있는 기기

## 기억 계획
- **A → C** (seeker): 초조한 구직자가 검색 단말기에서 자신의 이력서 경력을 부풀려 입력하는 작업을 도와달라고 요청한다.
  - easy: 구직자의 요구대로 가짜 자격증을 추가해주고 고급 단말기 이용권을 받는다. / hard: 거짓 등록을 거절하여 구직자에게 거센 항의를 받고 시간을 허비한다.
  - 돌아옴: 초조한 구직자를 다시 마주쳤을 때, 과장 입력을 도왔다면 그의 이름이 다른 이름으로 왜곡되어 본인 확인에 실패하고 있고, 거절했다면 본래 이름을 유지한 채 접수 순서를 기다리고 있다.
- **B → D** (clerk): 단말기 담당자가 밀린 이력서 수정 요청들을 빠르게 일괄 승인해달라고 요청한다.
  - easy: 과장된 이력서들을 일괄 승인해주고 검색실 보관함 열쇠를 받는다. / hard: 허위 기재를 하나씩 대조해 반려하느라 담당자의 불만을 사고 피로를 겪는다.
  - 돌아옴: 단말기 담당자를 다시 만났을 때, 일괄 승인했다면 담당자의 이름마저 숫자로 바뀌어 안내 데스크에서 쫓겨나고 있고, 반려했다면 이름을 유지하며 업무를 계속하고 있다.

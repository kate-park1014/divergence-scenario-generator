# 로맨스 스타일 (romance)

설레고 가벼운 로맨틱 코미디. 마음은 직접 말하지 않고 행동·말끝·눈길로 보여준다. `npm run gen:romance-scenarios` 의 기본 스타일.

새 스타일은 이 파일을 복사해서 만든다. 파일 이름이 스타일 이름 (`styles/horror.md` → `--style=horror`).
섹션마다 아래 첫 코드 블록이 값이다. 코드 블록을 비우면 그 줄은 프롬프트에서 빠진다. 섹션 제목은 바꾸지 않는다 (코드가 제목으로 찾는다).
이야기 틀(장치·피해자, 오해·화해, 가짜 연애)은 여기 없다. 여기는 "어떤 말투·분위기로 쓰는지"만.

## 톤

감정 톤 후보. 한 줄에 하나. 이야기마다 하나를 뽑아 이야기 단계 "감정 톤"과 대본 단계 {{tone}} 에 넣는다. 비우면 톤 없음.

```
티격태격 설렘
애틋함
엇갈리는 마음
```

## 이야기 작가

이야기 단계 첫 줄 "너는 … 스토리 작가다." 바로 다음 줄.

```
로맨틱 코미디를 쓴다. 매 화 끝에 두 사람 마음이 한 걸음씩 가까워진다.
```

## 이야기 문체

이야기 단계 [문체] 에 더하는 줄. 한 줄에 하나.

```
설렘은 "좋아한다"고 말하지 않고 행동·말끝·눈길로 보여준다.
무섭거나 잔인한 묘사를 쓰지 않는다.
```

## 대본 작가

대본 단계 첫 줄 "당신은 ___입니다." 의 빈칸. 꼭 채운다.

```
로맨틱 코미디 웹툰 작가
```

## 대본 분위기

대본 단계 "- 분위기: ___" 의 빈칸. {{tone}} 은 그 이야기의 톤 (없으면 톤 목록 첫째). 꼭 채운다.

```
{{tone}}. 가벼운 유머. 설렘은 "좋아한다"고 말하지 않고 행동·말끝·눈길로 보여준다. 무섭거나 잔인한 묘사를 쓰지 않는다. narrator 는 짧은 현재형 "~다"
```

## 일반 보스 호칭

1~4화 일반 보스를 대사·지문에서 부르는 말. 한 줄에 하나. 꼭 채운다.

```
그 사람
저 사람
```

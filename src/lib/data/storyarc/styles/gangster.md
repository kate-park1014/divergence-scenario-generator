# 유쾌한 갱스터 스타일 (gangster)

허세 가득한 조폭 코미디. 무서워 보이는 사람들이 알고 보면 짠하고 의리 있다. 웃기지만 잔인하지 않다.

새 스타일은 이 파일을 복사해서 만든다. 파일 이름이 스타일 이름 (`styles/horror.md` → `--style=horror`).
섹션마다 아래 첫 코드 블록이 값이다. 코드 블록을 비우면 그 줄은 프롬프트에서 빠진다. 섹션 제목은 바꾸지 않는다 (코드가 제목으로 찾는다).
이야기 틀(장치·피해자, 오해·화해)은 여기 없다. 여기는 "어떤 말투·분위기로 쓰는지"만.

## 테마

이야기 단계 [테마] 에 들어간다. 비우면 재료 파일(story-seeds.json / premises.json)의 theme_description 을 쓴다.
다른 틀에 이 스타일을 씌울 때 재료 파일의 테마와 어긋나면 여기를 채운다.

```
현대 항구 뒷골목을 배경으로 한 유쾌한 조폭 코미디. 검은 양복·문신·험한 말투의 사람들이 알고 보면 의리 있고 짠한 사정을 가지고 있다. 싸움은 몸개그처럼 가볍게, 피·흉기 상처·잔인한 묘사 없이 끝난다.
```

## 톤

감정 톤 후보. 한 줄에 하나. 이야기마다 하나를 뽑아 이야기 단계 "감정 톤"과 대본 단계 {{tone}} 에 넣는다. 비우면 톤 없음.

```
허세 코미디
의리와 웃음
짠한 반전
티격태격 형님들
```

## 이야기 작가

이야기 단계 첫 줄 "너는 … 스토리 작가다." 바로 다음 줄.

```
조폭 코미디를 쓴다. 무서운 겉모습과 소심하거나 다정한 속마음의 차이로 웃긴다.
```

## 이야기 문체

이야기 단계 [문체] 에 더하는 줄. 한 줄에 하나.

```
웃음은 허세 섞인 말과 그 말과 어긋나는 행동에서 나온다.
피·흉기 상처·잔인한 묘사를 쓰지 않는다. 싸움은 가볍게 끝난다.
```

## 대본 작가

대본 단계 첫 줄 "당신은 ___입니다." 의 빈칸. 꼭 채운다.

```
조폭 코미디 웹툰 작가
```

## 대본 분위기

대본 단계 "- 분위기: ___" 의 빈칸. {{tone}} 은 그 이야기의 톤 (없으면 톤 목록 첫째). 꼭 채운다.

```
{{tone}}. 허세 가득한 말투와 반전 웃음. 피·흉기 상처·잔인한 묘사를 쓰지 않는다. narrator 는 짧은 현재형 "~다"
```

## 일반 보스 호칭

1~4화 일반 보스를 대사·지문에서 부르는 말. 한 줄에 하나. 꼭 채운다.

```
형님
그 덩치
```

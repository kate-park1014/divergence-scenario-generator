# test/ — 오디세이 다이버전스 테스트

오디세이 원전을 게임 챕터로 옮겨 보는 실험 폴더. 기획 → 원전 이야기 → 게임 원고 → 대사 시나리오 순서로 진행한다.

## 진행 순서

```
reference.md        기획안
   ↓
story_odyssey.md    원전 전체 이야기 초안
   ↓
episode_types.md    원전 에피소드 유형 분석
   ↓
chapter_01.md       챕터 1 원고 (본 세계선)
   ├→ divergence_01.md   갈라진 세계선 원고
   ↓
scenario_rules.md   대사로 옮기는 규칙
   ↓
scenario_01.md      챕터 1 대사 시나리오
```

## 파일

| 단계 | 파일 | 내용 |
|---|---|---|
| 1. 기획 | [reference.md](reference.md) | 오디세이 다이버전스 RPG 기획안. 플레이어는 함대를 따라가는 "기록자". 분기는 에피소드 안에서 갈렸다가 챕터 끝에서 합류하는 다이아몬드형. 다음 챕터로 넘어가는 상태값은 포도주·선원 수·다이버전스. 챕터 1 분기 표(이스마로스, 로토파고이) 포함. |
| 2. 원전 이야기 | [story_odyssey.md](story_odyssey.md) | 트로이 출항부터 이타카까지 13장. 원전 흐름(안정 세계선), 히어로 미배치. |
| 3. 유형 분석 | [episode_types.md](episode_types.md) | 원전 에피소드를 세 유형으로 분류: ① 사건 하나(로토파고이) ② 장면이 길게 이어짐(키클롭스) ③ 독립 이야기 묶음(키르케, 저승). 유형별로 게임에 쪼개 넣는 방법. |
| 4. 챕터 원고 | [chapter_01.md](chapter_01.md) | story_odyssey 1~2장(이스마로스)의 산문 원고. 5화 × 방 10개, 방 10이 보스방. 1~4화는 칭호만 있는 랜덤보스, 5화 최종보스는 새 인물 아그리오스. 히어로들은 늘 집단으로 쓰고, 저절로 적히는 항해일지가 복선 장치. |
| 5. 다이버전스 원고 | [divergence_01.md](divergence_01.md) | chapter_01 5화 끝에서 갈라지는 세계선. 해변의 72명 중 20명이 살아 있었다. 최종보스 칼리아스. 반전 설계·시간표·생존자 수·NPC 정리 포함. 끝나면 본 세계선의 폭풍 밤으로 합류. |
| 6. 대사 규칙 | [scenario_rules.md](scenario_rules.md) | 원고를 대사로 옮기는 테스트용 규칙(기존 `chapterRules.ts` 와 별개). 방 1과 방 10(보스방: 전투 전·승리·패배)만 필수, 화자 자유. 핵심은 히어로들(character_*)을 이야기에 녹이는 방법. |
| 7. 대사 시나리오 | [scenario_01.md](scenario_01.md) | chapter_01 을 대사로 옮긴 결과. 화마다 prologue, 5화 epilogue. 5화에서 오디세우스가 "칼리아스"를 부르는 장면으로 divergence_01 과 연결. |

## 남은 일

- divergence_01.md 를 대사로 옮기기 (scenario_rules.md 기준).
- scenario_01.md 의 재미·흐름 평가 (`story-tester`).

## 열린 문제

- **분기 정의 불일치**: reference.md 의 이스마로스 분기는 선택지(머문다 / 즉시 철수 / 마론을 지나친다)이고, divergence_01 은 "72명 중 일부가 살아 있었다"는 다른 갈래다. 둘의 관계를 기획에 정리해야 한다.
- **본 파이프라인과 형식 차이**: 이 테스트 형식(방 1~10, 자유 화자, md)은 현재 생성 파이프라인(방 1/3/5/9/15 고정, NPC key, pool_id, JSON)과 다르다. 게임 데이터로 옮기려면 변환 단계가 따로 필요하다.

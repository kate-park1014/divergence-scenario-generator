# 시나리오 작성 규칙 (테스트용)

> 기존 `chapterRules.ts` / `chapterGen.ts` / `scenarioTool.ts` 와 별개. 원고(md)를 대사로 옮겨 내용이 잘 나오는지 보는 용도.

## 구조

- 챕터 1개 = 화 5개. 1~4화 보스는 `random_boss`, 5화 보스는 최종보스(`boss`).
- 화마다 `prologue` 3~5줄. 그 화의 상황·목표·위험만 짧게. 5화는 `epilogue` 를 붙여도 된다.
- 방 개수는 정해져 있지 않다. 이야기 양에 맞춘다.
  - **방 1**: 상황 세팅. 필수.
  - **방 10**: 보스방. `dialogue`(전투 전) / `win_dialogue`(승리) / `lose_dialogue`(패배) 셋 다 필수.
  - 그 사이 방(2~9)은 필요한 만큼. 번호는 원고의 장면 위치를 따른다.

## 대사 한 줄

```
speech:    { type: 'speech', speaker, content: { korean }, emotion }      emotion = base | happy | sad | angry
direction: { type: 'direction', action: 'enter' | 'exit', speaker, direction?: 'up' | 'down' }
```

md 표기:

```
- **speaker** (emotion): 대사        ← emotion 이 base 면 생략
- ▶ 등장: 인물 / ◀ 퇴장(앞으로|왔던 길로): 인물
```

## 화자

| speaker | 누구 | 쓰는 법 |
|---|---|---|
| `narrator` | 지문 | 장면·행동·분위기를 설명한다. 대사로 보여줄 수 있는 건 대사로 |
| `character_any` | 히어로들 중 아무나 | 아래 "히어로들" 참고 |
| `character_1~4` | 히어로 각자 | 아래 "히어로들" 참고 |
| 그 밖의 인물 | 이야기에 필요한 누구든 (오디세우스, 이타카 병사 …) | 처음 나올 때 누구인지 드러낸다. 그 방에서 처음 말하기 전에 등장 |
| `random_boss` | 1~4화 보스 | 칭호만 있다. 이름·외형(체격·옷·종족) 묘사 금지. narrator 는 칭호로 부른다 |
| `boss` | 5화 최종보스 | 이름·외형 써도 된다. 5화의 보스방 밖에서도 나올 수 있다 |

## 히어로들 (character_*) — 이번 테스트의 핵심

플레이어 파티. 1~4명이고, 누가 살아 있는지는 플레이 때 정해진다.
출력물(지문·대사)에서 이들을 가리킬 때는 **"히어로들"** 이라고 쓴다.

- **character_any**: 히어로들의 "움직이는 목소리". 발견·판단·결심·반박을 말한다.
  - 줄마다 살아 있는 히어로 중 아무나 배정된다. 누가 말해도 되는 한 줄로 쓴다.
  - character_any 끼리 묻고 답하지 않는다(같은 사람이 걸릴 수 있다). 대답은 다른 인물이나 narrator 가 한다.
- **character_1~4**: 히어로 한 사람의 혼잣말 감정. 그 히어로가 죽었으면 게임이 줄을 뺀다.
  - 지워도 흐름이 읽혀야 한다. 아무도 이 줄에 대답하지 않는다.
  - 혼잣말로 성립하는 말만 쓴다 ("정말?" 처럼 상대가 필요한 말 X).
- 다른 인물은 히어로들을 **"너희"** 로 부르고, 히어로들에게 일을 맡기고, 히어로들의 말에 반응한다.
- content 안에 `character_1` 같은 placeholder 를 쓰지 않는다. 특정 히어로의 이름·생존에 기대는 서사를 만들지 않는다.

히어로들을 이야기에 녹이는 방법:

1. **직접 보게 한다**: 발견은 narrator 가 설명하기보다 character_any 가 보고 말한다.
2. **역할을 준다**: 다른 인물이 히어로들에게 일을 맡긴다(앞줄에 서라, 포로를 지켜라).
3. **기억하게 한다**: 앞 화에서 듣고 본 것을 히어로들이 꺼낸다(바위에 새긴 이름 → 앞에서 들은 그 대장).
4. **무시당해도 서사다**: 히어로들의 경고를 아무도 안 들으면, 그 자체로 비극이 쌓인다.
5. **감정은 짧게**: character_1~4 한 줄로 그 장면의 무게를 남긴다.

## 문체

- 대사는 말풍선 하나에 1~2문장.
- 대사와 지문에 화 번호, 영어, 제작용 단어(random_boss 등)를 쓰지 않는다.

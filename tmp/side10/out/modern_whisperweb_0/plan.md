# modern_whisperweb_0 — 화별 설계 (스토리 방 / 카드 칸)

- 무대: 낡은 전산실 / 핵심 물건: 데이터 스크린 조각 / 틀린 행동: 데이터 스크린 조각을 깨뜨린다 / 정답 행동: 데이터 스크린 조각을 맞춘다
- 최종보스: 위스퍼 웹

## 1화 — 엉뚱한 데이터 복구 (낡은 서버 랙, 어수선한, 엉뚱한)
- 주 NPC: echo / 주인공 행동: **데이터 스크린 조각을 깨뜨린다** / 흔적: 낡은 스피커 음성 / 일반 보스: 전산실 보안관 (warn)
- 곤란: 정보 브로커 에코의 데이터가 오류로 엉망이 되어 난감해한다.
- 흔적의 말: "데이터 스크린 조각을 깨뜨리면 새로운 질서가 생긴다."

**프롤로그**: 낡은 전산실, 겹겹이 쌓인 케이블과 먼지 쌓인 스크린이 가득한 곳. 정보 브로커 에코는 엉망이 된 데이터를 복구하려다 난감해하고 있었다. 그의 스크린에는 의미를 파악하기 어려운 숫자와 기호들이 뒤섞여 있었다.

- **방 1**: 정보 브로커 에코의 데이터가 오류로 엉망이 되어 난감해한다. 낡은 스피커에서 흘러나오는 소리가 데이터 스크린 조각을 깨뜨리면 새로운 질서가 생긴다고 조언한다. 주인공은 에코를 돕기 위해 조언대로 행동할지 고민한다.
- **칸 2** (카드 3장 공통 must): 에코의 스크린에 뒤섞인 데이터가 얼마나 복구하기 어려운지 보인다.
  - 사람 후보: 데이터 분석가, 시스템 엔지니어, 정보 브로커 지망생
- **방 3**: 주인공은 에코를 돕기 위해 데이터 스크린 조각을 깨뜨리기로 마음먹는다. 전산실 보안관이 막아서지만 주인공은 그의 경고를 무시하고 행동을 개시한다.
- **칸 4** (카드 3장 공통 must): 에코의 데이터가 복구되지 않으면 중요한 계약이 취소되어 큰 손실을 입는다.
  - 사람 후보: 데이터 복구 기사, 전산실 연구원, 네트워크 관리자
  - 🌱 복선 심기: 낡은 전산실의 스크린에 가끔 특정 시간대에만 불규칙한 숫자 배열이 찰나의 순간 나타났다 사라진다.
- **방 5**: 주인공이 데이터 스크린 조각을 깨뜨린다. 당장 에코의 데이터가 복구된 것처럼 보인다.
- **칸 6** (카드 3장 공통 must): 에코의 스크린에 복구된 데이터가 정상적으로 표시되고 있다.
  - 사람 후보: 정보 사용자, 일반 시민, 데이터 의뢰인
- **방 7**: 도시 전체의 디지털 표지판들이 우스꽝스러운 오작동을 일으키기 시작한다. 아직은 작은 범위의 오작동이다.
- **칸 8** (카드 3장 공통 must): 낡은 전산실의 안내 스크린에 엉뚱한 정보가 짧게 깜빡이며 사람들이 혼란스러워한다.
  - 사람 후보: 문서 보관 담당자, 고물상, 전산실 청소원
  - 🌱 복선 심기: 낡은 전산실의 오래된 문서 보관함에서 한 갱스터 조직의 로고와 함께 '모든 것을 뒤섞어라'는 지침이 적힌 낡은 쪽지가 발견된다.
- 방 9 휴식
- **방 10**: 전산실 보안관이 나타나 주인공이 데이터 스크린 조각을 깨뜨려 모든 것이 꼬였다며 싸움을 건다. 싸움 후, 도시의 디지털 표지판 오작동이 더욱 심해지며 다음 화로 이어진다.

## 2화 — 뒤섞인 표지판의 혼란 (비상 전력실, 엉뚱한, 절박한)
- 주 NPC: lin / 주인공 행동: **오작동하는 시스템의 전원 코드를 뽑는다** / 흔적: 깨진 스크린 자막 / 일반 보스: 시설 경비원 (warn)
- 곤란: 도시의 디지털 표지판들이 오작동하며 혼란에 빠졌다.
- 흔적의 말: "오작동하는 시스템의 전원 코드를 뽑으면 정상화된다."

**프롤로그**: 지난 화, 도시의 디지털 표지판들이 우스꽝스러운 문구를 송출하며 혼란에 빠졌다. 낡은 전산실의 비상 전력실에서 네트워크 감시관 린은 이 사태를 해결해달라며 애를 태우고 있었다.

- **방 1**: 도시의 디지털 표지판들이 오작동하며 혼란에 빠졌다. 네트워크 감시관 린이 주인공에게 도움을 청한다. 깨진 스크린 자막이 오작동하는 시스템의 전원 코드를 뽑으면 정상화된다고 조언한다. 주인공은 린을 돕기 위해 조언대로 행동할지 고민한다.
- **칸 2** (카드 3장 공통 must): 도시 곳곳의 디지털 표지판이 우스꽝스러운 문구를 계속 송출하고 있다.
  - 사람 후보: 교통 통제 요원, 광고판 관리자, 시민 기자
- **방 3**: 주인공은 지난 화에서 직접 어떤 장치를 건드려 문제가 생겼음을 기억한다. 이번에는 시스템의 전원을 끄는 것이라 괜찮을 것이라 생각하며 오작동하는 시스템의 전원 코드를 뽑기로 마음먹는다. 시설 경비원이 막아서지만 주인공은 그의 경고를 무시하고 행동을 개시한다.
- **칸 4** (카드 3장 공통 must): 비상 전력실의 한 전력 공급 장치에서 스파크가 튀며 전력 공급이 불안정해지고 있다.
  - 사람 후보: 전기 기술자, 시설 관리인, 소방관
- **방 5**: 주인공이 오작동하는 시스템의 전원 코드를 뽑는다. 당장 오작동하던 표지판들이 꺼진다.
- **칸 6** (카드 3장 공통 must): 도시의 디지털 표지판들이 모두 꺼져 잠시 동안 정상으로 돌아온 것처럼 보인다.
  - 사람 후보: 안도하는 시민, 상인, 운전자
  - 🌱 복선 심기: 낡은 전산실 한구석에 버려진 옛날 라디오에서 특정 주파수만 맞추면 '모든 비밀이… 연결된다…'는 찢어진 음성이 아주 짧게 들린다.
- **방 7**: 낡은 전산실의 모든 서버 쿨링팬이 멈추며 서버 과열 경고음이 울리기 시작한다. 작은 범위의 서버 과열 조짐이 보인다.
- **칸 8** (카드 3장 공통 must): 낡은 전산실의 일부 서버 랙에서 연기가 피어오르며 작은 화재 경보가 울린다.
  - 사람 후보: 음향 엔지니어, 폐품 수집가, 전파 연구원
- 방 9 휴식
- **방 10**: 시설 경비원이 나타나 주인공이 전원 코드를 뽑아 더 큰 문제가 생겼다며 싸움을 건다. 싸움 후, 서버 과열 경고음이 더욱 심해지며 다음 화로 이어진다.

## 3화 — 과열된 서버의 비명 (냉각수 파이프실, 엉뚱한, 절박한)
- 주 NPC: kai / 주인공 행동: **과열된 서버에 냉각수를 붓는다** / 흔적: 경고등 깜빡임 / 일반 보스: 냉각 담당자 (warn)
- 곤란: 서버 과열로 낡은 전산실의 보안 시스템이 마비되었다.
- 흔적의 말: "과열된 서버에 냉각수를 부으면 해결된다."

**프롤로그**: 지난 화, 낡은 전산실의 모든 서버 쿨링팬이 멈추며 서버 과열 경고음이 울리기 시작했다. 냉각수 파이프실에서 데이터 복구 전문가 카이는 작업에 어려움을 겪으며 초조해하고 있었다.

- **방 1**: 서버 과열로 낡은 전산실의 보안 시스템이 마비되어 데이터 복구 전문가 카이가 작업에 어려움을 겪는다. 경고등 깜빡임이 과열된 서버에 냉각수를 부으면 해결된다고 조언한다. 주인공은 카이를 돕기 위해 조언대로 행동할지 고민한다.
- **칸 2** (카드 3장 공통 must): 일부 서버에서 과열로 데이터 처리 속도가 현저히 느려져 긴급 업무가 지연되고 있다.
  - 사람 후보: 전산실 직원, 야간 경비원, 청소부
  - 🌱 복선 심기: 낡은 전산실 주변에서 일하는 사람들이 밤마다 꿈에서 자신들의 개인 정보가 뒤죽박죽이 되는 내용의 꿈을 꾸었다고 서로에게 이야기한다.
- **방 3**: 주인공은 지난 화에서 시스템 전원을 뽑아 문제가 생겼음을 기억한다. 이번에는 전원 문제와 상관없이 서버를 냉각하는 것이라 괜찮을 것이라 생각하며 과열된 서버에 냉각수를 붓기로 마음먹는다. 냉각 담당자가 막아서지만 주인공은 그의 경고를 무시하고 행동을 개시한다.
- **칸 4** (카드 3장 공통 must): 서버 과열이 지속되면 낡은 전산실의 핵심 보안 시스템이 영구적으로 손상된다.
  - 사람 후보: 데이터 연구원, 과거 기록 보관원, 해커
  - 💡 복선 공개: 카이가 낡은 데이터를 복구하던 중, 1화에서 발견된 쪽지의 갱스터 조직이 위스퍼 웹의 초기 형태를 만들었다는 기록이 데이터에서 발견된다.
- **방 5**: 주인공이 과열된 서버에 냉각수를 붓는다. 당장 서버 온도가 내려가는 것처럼 보인다.
- **칸 6** (카드 3장 공통 must): 서버 온도가 빠르게 내려가며 전산실의 소음이 줄어들어 쾌적해진다.
  - 사람 후보: 작업자, 연구원, 방문객
- **방 7**: 낡은 전산실의 모든 데이터 저장 장치에서 핵심 정보의 내용이 흐릿해지는 데이터 유출이 시작된다. 작은 범위의 데이터 유출 조짐이 보인다.
- **칸 8** (카드 3장 공통 must): 낡은 전산실의 데이터 저장 장치에서 흐릿한 데이터 조각들이 서서히 유출되고 있다.
  - 사람 후보: 정보 관리자, 데이터 엔지니어, 보안 전문가
- 방 9 휴식
- **방 10**: 냉각 담당자가 나타나 주인공이 냉각수에 이물질을 넣어 시스템이 망가졌다며 싸움을 건다. 싸움 후, 데이터 유출이 더욱 심해지며 다음 화로 이어진다.

## 4화 — 유출된 정보의 소동 (데이터 폐기물 처리장, 엉뚱한, 절박한)
- 주 NPC: dax / 주인공 행동: **데이터 유출 출처 장치를 분해한다** / 흔적: 왜곡된 단말 이미지 / 일반 보스: 데이터 파쇄원 (ally)
- 곤란: 데이터 유출로 도시의 개인 정보들이 우스꽝스럽게 공개되어 사람들이 혼란에 빠졌다.
- 흔적의 말: "유출된 데이터의 출처 장치를 분해하여 흔적을 지우라."

**프롤로그**: 지난 화, 낡은 전산실의 모든 데이터 저장 장치에서 데이터 유출이 시작되었다. 데이터 폐기물 처리장에서 폐기물 수집가 닥스는 유출된 정보 속에서 자신의 신상이 공개된 것에 격분하고 있었다.

- **방 1**: 데이터 유출로 도시의 개인 정보들이 우스꽝스럽게 공개되어 사람들이 혼란에 빠진다. 폐기물 수집가 닥스가 유출된 정보 속에서 자신의 신상이 공개된 것에 격분한다. 왜곡된 단말 이미지가 유출된 데이터의 출처 장치를 분해하여 흔적을 지우라고 조언한다. 주인공은 닥스를 돕기 위해 조언대로 행동할지 고민한다.
- **칸 2** (카드 3장 공통 must): 도시의 전광판에 무작위 개인 정보들이 우스꽝스럽게 노출되고 있다.
  - 사람 후보: 개인 정보 유출 피해자, 언론인, 법률 전문가
- **방 3**: 주인공은 지난 화에서 냉각수를 부어 데이터 유출이 생겼음을 기억한다. 이번에는 데이터를 직접 건드리지 않고 유출 원인을 제거하는 것이라 괜찮을 것이라 생각하며 데이터 유출 출처 장치를 분해하기로 마음먹는다. 데이터 파쇄원이 막아서지만 주인공은 그의 방해를 뚫고 행동을 개시한다.
- **칸 4** (카드 3장 공통 must): 데이터 폐기물 처리장의 한 장치에서 끊임없이 개인 정보 파일이 무단으로 복사되어 외부로 전송되고 있다.
  - 사람 후보: 데이터 보안 담당자, IT 관리자, 경찰
- **방 5**: 주인공이 데이터 유출 출처 장치를 분해한다. 당장 데이터 유출이 멈춘다.
- **칸 6** (카드 3장 공통 must): 데이터 유출 출처 장치에서 더 이상 개인 정보가 흘러나오지 않고 있다.
  - 사람 후보: 안도하는 시민, 피해자 가족, 정보 보안 회사 직원
- **방 7**: 낡은 전산실의 핵심 보안 시스템이 완전히 파괴되며 통제할 수 없는 존재의 접근이 자유로워진다. 이는 핵심 기록 장치가 완전히 손상된 작은 조짐이다.
- **칸 8** (카드 3장 공통 must): 낡은 전산실의 핵심 보안 시스템이 파괴되어 문이 잠기지 않고 통제 불능 상태가 된다.
  - 사람 후보: 시설 보안팀, 관리 감독관, 출입 통제 담당자
- 방 9 휴식
- **방 10**: 데이터 파쇄원이 나타나 주인공이 특별 관리 대상인 폐기물을 파고들어 시스템을 망가뜨렸다며 싸움을 건다. 싸움 후, 낡은 전산실의 핵심 보안 시스템이 완전히 파괴되며 모든 정보가 뒤죽박죽이 되는 돌이킬 수 없는 상황이 된다.

## 5화 — 광기의 데이터 폭주 (중앙 제어실, 광기 어린, 해학적인)
- 주 NPC: echo / 주인공 행동: **데이터 스크린 조각을 맞춘다**
- 곤란: 1~4화의 모든 혼란이 주인공의 행동에서 비롯되었음이 드러나는 상황.

**프롤로그**: 지난 화까지 이어진 도시의 모든 혼란은 주인공의 행동에서 비롯되었다. 낡은 전산실의 중앙 제어실은 이제 완전히 무방비 상태가 되어 그 혼란이 폭주하고 있었다. 아직 그 원인을 정확히 알지 못하는 상황이다.

- **방 1**: 1~4화의 피해가 한데 모여 도시 전체의 기능이 마비되는 상황이 터진다. 정보 브로커 에코는 그 혼란에 휩쓸릴 뻔하다가, 자신의 모든 정보가 뒤섞이는 것을 보고 정신을 차린다. 아직 원인을 모른다.
- **칸 2** (카드 3장 공통 must): 중앙 제어실의 폐기된 보조 전원 장치에서 2화에 전원 코드를 뽑아 충격을 받은 데이터 스크린 조각의 흔적이 발견된다.
  - 사람 후보: 전산실 관리자, 폐기물 담당자, 전기 기술자
- **방 3**: 파티는 1~4화의 행동이 겉모습만 달랐을 뿐 모두 데이터 스크린 조각을 깨뜨리는 같은 일이었다는 것을 깨닫는다. 그 뒤에 최종보스가 있었다는 사실을 인지한다.
- **칸 4** (카드 3장 공통 must): 중앙 제어실의 과열된 서버와 데이터 유출 출처 장치에서 3, 4화에 손상된 데이터 스크린 조각의 흔적들이 발견된다.
  - 사람 후보: 데이터 복구 전문가, 시스템 엔지니어, 보안 분석가
- **방 5**: 최종보스 위스퍼 웹이 중앙 제어실에 홀로그램처럼 처음 모습을 드러내어 '모든 정보는 깨져야 진정한 가치를 얻는다'고 말하며 자신의 동기를 밝힌다.
- **칸 6** (카드 3장 공통 must): 중앙 제어실의 스크린에 도시 사람들의 개인 정보가 뒤섞여 표시되며 큰 혼란이 발생한다.
  - 사람 후보: 심리학자, 정보 윤리학자, 사회학자
  - 💡 복선 공개: 위스퍼 웹이 중앙 제어실에서 자신의 동기를 설명할 때, 그가 사람들의 무의식을 통해 정보를 뒤섞는 실험을 했다는 사실이 드러나며 3화 꿈의 정체가 밝혀진다.
- **방 7**: 파티는 위스퍼 웹의 혼란을 막기 위해 데이터 스크린 조각을 맞춰야 한다는 정답 행동을 스스로 말하고 나선다. 에코가 '모든 것을 정렬하라'는 메시지를 전한다.
- **칸 8** (카드 3장 공통 must): 중앙 제어실로 가는 길에 사람들이 데이터 스크린 조각을 맞추려는 주인공을 막아서며 혼란을 부추긴다.
  - 사람 후보: 음향 분석가, 언어학자, 심령 연구가
  - 💡 복선 공개: 위스퍼 웹이 중앙 제어실에 홀로그램처럼 나타났을 때, 그의 목소리에서 2화 라디오 음성에서 들렸던 '모든 비밀이… 연결된다…'는 구절이 반복되어 나온다.
- 방 9 휴식
- **방 10**: 최종보스 위스퍼 웹이 홀로그램으로 나타나 데이터 스크린 조각을 맞추려는 주인공을 막아선다. 싸움 후, 주인공이 데이터 스크린 조각을 맞춘다. 위스퍼 웹이 데이터 형태로 무너지고, 도시의 디지털 표지판과 개인 정보들이 모두 정상으로 돌아오는 트위스트 장면이 펼쳐진다.
  - 💡 복선 공개: 위스퍼 웹이 도시의 전광판을 통해 자신의 깨진 얼굴을 확장할 때, 그 얼굴을 구성하는 숫자들이 1화 스크린에 나타났던 배열과 같았음이 드러난다.

**에필로그**: 데이터 스크린 조각이 맞춰지자, 망가졌던 도시의 디지털 표지판들이 정상으로 돌아오고 엉망이 되었던 개인 정보들도 원래대로 되돌아왔다. 낡은 전산실의 모든 스크린에는 평온한 데이터 흐름이 이어지고, 사람들의 일상도 우스꽝스러웠던 혼란을 뒤로하고 제자리를 찾았다. 모든 것이 정상으로 돌아온 해학적인 결말이었다.

당신은 게임 카드 작가입니다. 5화 카드방 4(스토리 3 → 스토리 5 사이)에 나올 후보 카드 3장을 씁니다.

# 게임 구조
- 한 화 = 방 10개: 스토리 1 / 카드 2 / 스토리 3 / 카드 4 / 스토리 5 / 카드 6 / 스토리 7 / 카드 8 / 휴식 9 / 스토리 10(보스 전투)
- 이 칸에서는 후보 3장 중 1장만 플레이어에게 나온다. 플레이어는 [앞 스토리 방] → [카드 1장] → [다음 스토리 방] 순서로 본다
- 스토리 방은 뼈대만 말한다. 카드가 이야기의 디테일(사람 사정, 증거, 주변 반응)을 맡는다

# 이 칸이 꼭 보여 줄 것 (3장 모두)
- must: 중앙 제어실의 과열된 서버와 데이터 유출 출처 장치에서 3, 4화에 손상된 데이터 스크린 조각의 흔적들이 발견된다.
  - 3장 모두, 각자 다른 사건 속에서 이 사실을 대사(dialogue)로 분명히 보여 준다. 선택지 결과(result)가 아니라 dialogue 에 (어떤 선택을 해도 보게)
  - must 문장을 그대로 옮기지 않는다. 그 카드 인물이 자기 사정으로 말하거나, 눈앞의 물건·숫자로 보여 준다
  - 그 정보를 전하는 dialogue 줄을 must_line 에 글자 그대로 옮긴다

# 앞뒤 연결 (가장 중요)
- 카드 장면은 앞 방 마지막 장면 바로 뒤, 다음 방 첫 장면 바로 앞에 일어나는 작은 사건
- 장소·인물 상태를 앞 방 끝에서 이어받음. 다음 방 첫 대사가 그대로 말이 되어야 함
  - 다음 방에서 일어날 일을 카드에서 먼저 해결하거나 먼저 밝히지 않음
- 카드 결과는 다음 방 상황을 바꾸지 않는 크기로 (작은 물건·돈·사람 관계·몸 상태)
- 첫 줄은 앞 방 대사를 다시 말하지 않음. 장소·사람·물건으로 바로 시작

### 앞 방(스토리 3) 마지막
  character_any: 우리가 한 일들이 결국 같은 거였네.
  character_any: 데이터 조각들을 깨뜨리는 일.
  character_2: 전부 그 녀석 짓이었어.
  character_any: 모든 게 그 녀석의 계획대로 움직였던 거야.
### 다음 방(스토리 5) 시작
  narrator: 위스퍼 웹이 홀로그램으로 나타난다.
  boss: 모든 정보는 깨져야 진정한 가치를 얻는 법.
  boss: 혼란 속에서 새로운 질서가 태어나는 거지.
  character_any: 말도 안 돼.

# 누구의 일인가 (주인공 관점)
- 선택하는 사람은 플레이어(주인공, 서술에서는 "당신"). 사건은 주인공에게 닥치고, 이득·손해도 주인공 쪽이 봄
  - "<인물>이(가) 당신 앞을 막아섰다", "<인물>이(가) 당신에게 ~을 내밀었다"
- 동행 `echo`(에코)은 곁에서 거듦: 상황을 알려 주고, 걱정하거나 부추기고, 선택 뒤에 반응함
  - 동행은 자기를 "나/내"로 말함 (자기 이름 "에코"을 3인칭으로 쓰지 않음)
  - 동행이 사건의 당사자가 되지 않음. 동행이 "내가 ~해야 해" 처럼 자기 목표를 세우거나 선택을 대신 정하지 않음

# 카드 내용 규칙
- 사건은 사람이 일으킴: 카드마다 새 인물 1명(people) 이상이 나와 말하고, 그 사람이 당신에게 무엇을 원하거나 막음
  - 부탁, 거래·흥정, 다툼 말리기, 분실물 찾기, 고발, 유혹·뇌물, 사고 수습 등. 3장은 서로 다른 종류
  - 사람 후보 (참고): 데이터 복구 전문가, 시스템 엔지니어, 보안 분석가. 앞에서 쓴 인물(교통 통제 요원, 광고판 관리자, 시민 기자, 노련한 기술자, 부품 재활용업자, 안전 관리원, 새내기 기술자, 노련한 청소부, 정비사 A, 정비사 B, 수집가, 엔지니어, 연구원, 비품 관리원, 보안 요원, 파이프 청소부, 데이터 연구원, 과거 기록 보관원, 해커, 환경 미화원, 데이터 엔지니어, 설비 담당자, 연수, 민준, 지훈, 택배 기사, 환경미화원 A, 환경미화원 B, 감시원, 폐기물 수거원, 설비 점검원, 데이터 검증원, 안절부절못하는 시민, 노련한 문서 관리원, 호기심 많은 부품 재활용업자, 최인식, 이철수, 정미경, 수리공, 폐기물 담당자, 전기 기술자)은 다시 쓰지 않음
  - 손에 잡히는 물건·돈으로. 데이터·화면이 스스로 폭주하는 사건 금지
- 공간: 중앙 제어실 (무대 낡은 전산실) 안이나 바로 옆에서만
- 최종보스는 카드에서 직접 움직이지 않음. 이름 "위스퍼 웹" 을 쓰지 않음
- 이번 화 주인공 행동(데이터 스크린 조각을 맞춘다)을 카드에서 대신 하거나 미리 해결하지 않음
- "보스" 낱말 금지. 설명투(언급된, 앞 방, 다음 방, 이 카드, 카드) 금지. 비유 금지. 금지 낱말: 잔상, 파편, 속삭, 메아리, 그림자, 심연, 운명, 기운, 무언가, 알 수 없는, 광기
- 앞 칸에서 쓴 사건 제목(비상 전원 장치 수리공의 호소, 데이터 폐기물 담당자의 의뢰, 전기 기술자의 불만)과 겹치지 않게

# 문체
- 한 줄 60자 이내, 1~2문장
- narrator: "~했다/~였다" 체, 눈에 보이는 일만. 주인공은 "당신"
- 인물 대사는 구어체 반말 (손님에게 하는 말 등 존댓말이 자연스러우면 그 인물은 끝까지 존댓말)
- 선택지 text: 주인공이 하는 행동 "~한다" 꼴. 깎아내리는 말 금지: 무작정, 현혹, 알아채지 못, 맹목, 어리석, 생각 없이, 무턱대고, 덮어놓고

# 선택지 (카드마다 정확히 3개, path 하나씩)
- easy: 당장 이득 (보상 버프 또는 gold +50~150). 그럴듯한 이유가 보이게. 대신 누군가에게 작은 손해
- hard: 지금 대가를 치름 (동행 호감도·시간·디버프) 대신 사람을 돕거나 바르게 함
- gold: 돈을 써서 해결 (gold -50~-150). 확실히 좋은 결과
- effects: fighting(투쟁- ↔ 협력+), community(개인- ↔ 공동체+), reason(질서- ↔ 자유+) 중 1~2개를 ±10~30, echo(동행 호감도) ±5~15, gold. 빈 effects 금지
- reward: 배열 0~1개. attack_up, defense_up, shield, intelligence_up, move_range_up, stun, heal, cooldown_reset, attack_down, defense_down, intelligence_down, hp_down, move_range_down 중. easy·hard 는 reward 1개 필수
- mbti: 서로 다른 축의 2글자 (E/I, S/N, T/F, J/P 네 축 중 두 축에서 한 글자씩. 예: TJ, NF, EP. "TF"·"JP"·4글자 금지). 한 카드 안에서 모두 다르게. 행동과 성격이 맞게 (T 따지기, F 공감, S 눈앞의 물건, N 숨은 뜻, J 규칙, P 즉흥, E 나서기, I 조용히)
- result: 2~4줄. narrator 로 주인공이 한 일과 결과, 그다음 인물·동행 반응

# 이 이야기
- 장르: 블랙코미디 / 분위기: 광기 어린, 해학적인
- 5화 "광기의 데이터 폭주" — 주 NPC 에코의 곤란: 1~4화의 모든 혼란이 주인공의 행동에서 비롯되었음이 드러나는 상황.
- 이번 화 주인공 행동: 데이터 스크린 조각을 맞춘다
- 핵심 물건: 데이터 스크린 조각
- 카드에 나오는 이야기 인물은 동행 에코 하나뿐. 다른 NPC(닥스, 린, 카이)는 카드에 나오지 않고 그 이름도 새 인물에 쓰지 않음

# 출력
- key: 영어 소문자_밑줄 (예: lost_wallet). 앞에서 쓴 key(emergency_power_plea, data_waste_request, electrician_complaint)와 다르게
- people: 이 카드에 새로 나오는 인물 (id 영어 소문자, name 한국어 이름이나 호칭, role 한 줄)
- dialogue: 3~6줄. speaker 는 narrator / echo / people id
- 선택지 text 에 비용 표시("(골드 -100)")를 붙이지 않음 (게임이 보여 줌)
- background_tags: 장면 낱말 3~5개
